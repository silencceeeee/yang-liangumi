# 【养】良谷米 · 新中式高端农产品电商首页（PC 横版）

## 文件
- `index.html`：完整首页（HTML + CSS + 内联线性图标），引用 `images/` 下的实拍素材。

- 换图：直接把 `images/` 下同名文件替换即可，宽高比例保持现有尺寸不变形。
- 当前页面所有新增原图均按原始宽高比完整显示，不使用 `object-fit:cover` 裁切。
- 价格（¥89 / ¥49 / ¥198）、评分、复购率、备案号等为排版占位数据，上线前请替换为真实信息。
- 素材来源为你提供的图像素材，商用发布前请确认品牌与肖像授权。
